# 引擎包

引擎包是 [oMLX](https://github.com/jundot/omlx)（Apache License 2.0，Copyright oMLX contributors）的一份副本：代码一行不改，只用螺壳实验室的证书重新签名、公证，以便主控按发布清单安装。版本写在每次的发布说明里。

- `LICENSE-oMLX.txt`：oMLX 的许可全文。
- `THIRD-PARTY-PACKAGES.txt`：引擎包自带的 Python 包清单（名字、版本、许可，来自各包的 METADATA；都是未改动的 PyPI 包）。其中 GPL / LGPL 的包未做改动，源码包附在各发布里或见 PyPI。
